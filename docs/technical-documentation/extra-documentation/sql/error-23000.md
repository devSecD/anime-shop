# Documentación del código de error SQL 23000

## SQLSTATE 23000: Violación de integridad de datos

**Descripción:**
El código de error SQLSTATE 23000 indica que se ha intentado realizar una operación que **viola alguna restricción de integridad de la base de datos**. Esto puede incluir claves primarias, claves únicas o claves foráneas.

### Casos comunes

| Escenario | Ejemplo | Código MySQL (errno) |
|-----------|---------|--------------------|
| Duplicado de clave única | Insertar un email que ya existe en una columna `PRIMARY KEY` o `UNIQUE` | 1062 |
| Violación de clave foránea al eliminar | Intentar eliminar un registro padre que tiene hijos relacionados | 1451 |
| Violación de clave foránea al insertar o actualizar | Insertar un registro hijo que apunta a un ID inexistente en la tabla padre | 1452 |
